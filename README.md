# Task 3: Data Visualization Portfolio
Retail sales 2025 (sample data) analysed with Matplotlib and Seaborn.

## Files
- dashboard.png - combined KPI dashboard
- 1_trend_line.png ... 5_scatter.png - individual charts
- retail_sales_raw.csv - raw data
- data_viz_portfolio.py - code (run: python data_viz_portfolio.py)

## Data story
- Q4 sales run about 40% above the Jan-Sep average: plan stock and campaigns early.
- Electronics leads sales, but Clothing earns the most profit (about 35% margin).
- West is the top region; South lags and needs a regional strategy.
- Grocery margin is thin (about 12%): avoid heavy discounting.
